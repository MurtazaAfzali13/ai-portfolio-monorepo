## Flagship Projects

### 1. VidBrain — Agentic Multi-Video Corrective RAG Platform
A system that turns YouTube video transcripts into a queryable knowledge base, solving the problem where conventional video RAG hallucinates when a question falls outside the indexed content.

- **Architecture:** Supervisor node routes each query as either single-video (pinned to one `video_id`) or general (aggregated across a user's full video catalog); a Retriever node performs metadata-filtered Pinecone search inside strict per-user namespaces; a Validator node grades retrieved context, and anything below the relevance threshold triggers a Tavily web-search fallback before generation.
- **Precision timestamps:** every answer traces back to the exact `video_id` and timestamp it came from, so users can jump straight to the right moment in the source video.
- **Chat persistence:** conversations are stored with automatic thread-title generation and non-blocking async I/O.
- **Enterprise analytics dashboard:** a role-aware (Admin vs. Regular user) observability layer built on Clerk RS256 JWT verification and a single auditable Supabase RPC function, with timeframe filtering (Today/Week/Month/All) and LangGraph node-execution visualizations.
- **Stack:** FastAPI, LangGraph, Pinecone, Tavily, Supabase, Clerk, Next.js.

### 2. Doctor Copilot — AI Clinical Platform (Watan Hospital)
An AI-assisted system for hospital doctors that turns a free-text (or dictated) encounter note into a checked, printable prescription.

- **Extractor agent:** structured-output LLM turns the doctor's note into patient, diagnosis, and medication data.
- **Safety Checker (RAG) agent:** cross-checks every newly prescribed medication against a Pinecone drug-interaction index and the patient's existing medications; high/critical-severity interactions block printing until a physician provides a mandatory clinical justification to override (fully audit-logged).
- **Patient Records Chat Agent:** a ReAct tool-calling loop that answers natural-language questions about a patient or refers them to a colleague — every answer is grounded in a real Supabase lookup, never fabricated.
- **Access control:** a treatment-relationship model enforced both at the Postgres Row-Level-Security layer and in application code, so a doctor can only see patients they actually treat.
- **Extras:** voice dictation (Whisper via OpenRouter), a PDF prescription generator matching the hospital's exact letterhead, and a daily analytics dashboard.
- **Testing:** 46/46 backend tests passing, fully mocked (no live API keys required).

### 3. Enterprise Multi-Agent Strategy Engine (active development)
A modular AI framework built on Clean Architecture and SOLID principles. A Supervisor node delegates tasks to specialized worker agents — Web Researcher, Document RAG, Fact-Checker — with Human-in-the-Loop checkpoints pausing execution for manual approval before any high-stakes action.
